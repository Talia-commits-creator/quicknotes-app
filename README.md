# QuickNotes App

QuickNotes is a simple note-taking application that lets users create, organize, search and delete notes by category.

## Features

- Add notes with Personal, Work and Study categories.
- Delete individual notes.
- Search notes without case sensitivity.
- Validate empty notes and notes longer than 200 characters.
- Display note counts.
- Save notes using localStorage.
- Responsive layout for mobile screens.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
